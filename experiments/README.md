# 实验记录

本目录保存**可提交的结论与配置**，不保存权重和原始日志。

命名：`experiments/YYYY-MM-DD-slug/`

每个实验目录至少包含 `README.md`：

```markdown
# 实验名

## 问题
## 数据与划分
## 配置
- seed:
- batch size:
- 学习率:
- 硬件:
## 复现命令
## 结果
| 指标 | 基线 | 方法 |
## 结论与限制
## 下一步
```

要求：

- 结论不超出实验证据；
- 至少包含基线；
- 失败的实验也要记录原因；
- 实际产物放在 `runs/`，本目录只引用路径和关键数字。

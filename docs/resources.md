# 学习资料

按“先建立直觉、再看实现、最后读论文”的顺序使用。链接仅供学习，内容以官方文档为准。

- Deep Learning Book：<https://www.deeplearningbook.org/>
- CS231n 课程笔记：<https://cs231n.github.io/>

## 使用建议

- 每个链接至少对应到一次可运行实验或一段 `notes.md`；
- 不要整篇复制教程代码，先写出自己的最小版本，再对照；
- 论文先读摘要、图和结论，再决定是否精读。

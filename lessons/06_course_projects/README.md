# 06 · 课程与科研专题

## 目标

把前面课程中的组件组合成一个可复现的小型项目，服务于课程作业、竞赛或科研预实验。

## 选题模板

1. **问题**：一句话说明要验证什么，避免“训练一个模型看看”。
2. **数据**：来源、规模、划分方式、是否允许公开。
3. **基线**：最简单的可用方法（逻辑回归/小 CNN/预训练模型）。
4. **指标**：主指标 + 辅助指标 + 误差棒。
5. **消融**：一次只改一个变量，记录配置与命令。
6. **结论**：在什么条件下成立，哪些没有验证。

## 目录约定

```text
experiments/YYYY-MM-DD-slug/
├─ README.md       # 问题、配置、命令、结果、结论
├─ config.yaml     # 可选
└─ notes.md        # 失败记录与下一步
```

`runs/` 保存实际权重与日志，默认不提交；重要结果以表格/图片形式放入 `experiments/` 并注明生成命令。

## 与课程要求的映射

在 [docs/course-mapping.md](../../docs/course-mapping.md) 中维护课程主题与本仓库 lesson/实验的对应关系，交付前检查覆盖情况。

## 验收标准

- [ ] 能从干净环境按 README 复现主结果；
- [ ] 基线、主方法、至少一个消融齐全；
- [ ] 结论不超出实验证据；
- [ ] 数据与产物没有误提交。
